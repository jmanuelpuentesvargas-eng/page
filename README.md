# Johan Official

Página web oficial ficticia de Johan con estilo oscuro, elegante y cinematográfico inspirado en el Decade World Tour.

## Cómo entrar a la página

La página está en `index.html`. Puedes abrirla de dos formas:

### Opción rápida

Haz doble clic en `index.html` para abrirla directamente en tu navegador.

### Opción recomendada con servidor local

Desde esta carpeta ejecuta:

```bash
npm start
```

Luego entra en tu navegador a:

```text
http://localhost:8000
```

Si no usas npm, también puedes ejecutar directamente:

```bash
python3 -m http.server 8000
```
